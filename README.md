## 👋 About me

I'm a **product designer** who designs digital products people actually enjoy using, from research and wireframes to polished UI and handoff.

What sets my work apart is my background. I'm also a **full-stack developer** and a **Mechanical & Manufacturing Engineering** student, so I design with real constraints in mind: how things get built, how they scale, and how they work in the physical world. That means smoother handoffs with engineers and fewer "this can't be built" surprises.

## 🎯 What I do

| | |
|---|---|
| **🎨 Product & UI/UX Design** | User research, flows, wireframes, prototypes, visual design, design systems |
| **💻 Design Engineering** | I build my own front ends and APIs, so I prototype in code when it's faster than a mockup |
| **⚙️ Systems Thinking** | Mechanical engineering training: tolerances, manufacturability, structured problem solving |

## 🛠️ My process

1. **Understand**: talk to users, define the real problem
2. **Explore**: sketch, map flows, test ideas fast
3. **Design**: high-fidelity UI, systems and components
4. **Build & Validate**: prototype, collaborate with engineers, iterate on feedback
